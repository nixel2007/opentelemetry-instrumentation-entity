# Справочник API

Библиотека дает два способа инструментирования entity — их можно включать по отдельности.

| Класс | Назначение |
| --- | --- |
| [ОтелНаблюдательИсточникаДанных](ОтелНаблюдательИсточникаДанных.md) | Наблюдатель источника данных: операции менеджера сущностей, запросы к СУБД, соединения и транзакции становятся спанами и метриками |
| [ОтелИнструментированиеХранилищаСущностей](ОтелИнструментированиеХранилищаСущностей.md) | Обертка вокруг хранилища сущностей: точка гистограммы на каждый вызов метода |

Наблюдатель регистрируется на источнике данных методом `ИсточникДанных.ДобавитьНаблюдателя`, обертка хранилища сущностей создается вызовом `Обернуть`.

Трейс строит наблюдатель: обертка хранилища сущностей спанов не создает, она только замеряет вызовы. Вызов метода хранилища сущностей виден в метриках, а операции entity и запросы к СУБД, которые метод выполнил, — в трейсе.

Ключи `db.*`, `server.*`, `error.type` и `code.*` берутся из модуля `ОтелСемантическиеСоглашения` SDK, гистограммы длительности — в секундах.

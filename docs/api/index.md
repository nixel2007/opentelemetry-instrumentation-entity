# Справочник API

Библиотека дает два способа инструментирования entity — их можно включать по отдельности.

| Класс | Назначение |
| --- | --- |
| [ОтелНаблюдательИсточникаДанных](ОтелНаблюдательИсточникаДанных.md) | Наблюдатель источника данных: операции менеджера сущностей, запросы к СУБД, соединения и транзакции становятся спанами и метриками |
| [ОтелИнструментированиеХранилищаСущностей](ОтелИнструментированиеХранилищаСущностей.md) | Обертка вокруг хранилища сущностей: спан и точка гистограммы на каждый вызов метода |

Наблюдатель регистрируется на источнике данных методом `ИсточникДанных.ДобавитьНаблюдателя`, обертка хранилища сущностей создается вызовом `Обернуть`. Вместе они дают вложенность: вызов метода хранилища сущностей — корневой спан, операции entity и запросы к СУБД внутри него — дочерние.

Общее для обоих: `Неопределено` вместо трассировщика выключает спаны, `Неопределено` вместо метра — метрики. Ключи `db.*`, `server.*`, `error.type` и `code.*` берутся из модуля `ОтелСемантическиеСоглашения` SDK, гистограммы длительности — в секундах.
